# Simulating-Resources

Code, data and stored results for **Chapter 3, "Simulating resources"**, of the
PhD thesis of N. Gambaro. The chapter derives a continuous dynamical system with
delays for the anthropogenic metal cycle and its market (DMMCM), estimates it
on the global copper cycle 1961–2022, assesses identifiability by profile
likelihood, and studies how the mining lead time $\tau_E$ shapes copper price
cycles, supply, flows and stocks.

> [!IMPORTANT]
> **`model_v1.R` is the code of the published paper, not the thesis model.**
>
> Gambaro, N., Brito-Parada, P., Glöser-Chahoud, S. and Plancherel, Y. (2025).
> Simulating resource movements and markets: A continuous dynamical system with
> delays to model anthropogenic metal cycles. *Resources Policy* 103, 105548.
> <https://doi.org/10.1016/j.resourpol.2025.105548>
>
> It is kept here unchanged so that the published results stay reproducible.
> Thesis Chapter 3 uses a **revised and refitted** model (`model_v2.R`, estimated
> with `run_all.R`), whose parameter values differ from those reported in the
> paper. When quoting numbers, cite the paper for `model_v1.R` and the thesis
> chapter for everything else. The main changes from v1 to v2 are documented in
> the header of `model_v2.R`: the system is cast in retarded rather than neutral
> form, the recycling constraint is enforced algebraically, a cost anchor
> $C(t)$ replaces the additive price drift, and price enters the *level* of
> demand rather than its growth rate.

All result files carry the suffix `__slade_cycle_drop_core`, the configuration
reported in the chapter: Slade cost anchor (`cost=slade`), cycle-matching
objective (`loss=cycle`), redundant series dropped (`redundant=drop`), the
twelve-parameter core set (`free=core`), no effective-sample-size weighting
(`eff=off`).

## Requirements

R 4.3.0 with `deSolve` 1.36, pinned in `renv.lock`. `DEoptim` is listed for the
optional `global=de` pre-stage of `run_all.R`, which was not used for the
reported fit. On first opening the folder, `.Rprofile` bootstraps `renv`; then

```r
renv::restore()
```

## Reproducing the results

From a terminal in the repository folder:

```sh
make plot      # minutes: figures, metrics and trajectories from the stored fit
make figures   # residual diagnostics
make sweep     # delay / demand-form experiments at the fitted parameters
make diag      # sensitivities and collinearity at the fit
```

These read the stored `state_fit__slade_cycle_drop_core.rds` and reproduce the
chapter's figures and numbers without re-estimating anything.

Re-estimation from scratch (`make fit`, `make profile`, or `make cycle` for the
whole chain) takes hours to days on a laptop. Every target resumes from its
`state_*.rds`, so an interrupted run can simply be repeated; do not change
`starts=`, `seed=` or `free=` on a resume. Run `make fit` only after moving the
shipped state files out of the way, otherwise it resumes from them.

### Provenance of the reported fit

The stored fit was not produced by a single command. In order:

1. Latin-hypercube multistart, 24 candidates plus the centre
   (`state_multistart__…rds`, `multistart__…csv`, 25 August 2026).
2. Profile likelihoods against that fit. A grid point improved on it and was
   written out as a promotable seed (`state_profile_best__…rds`).
3. Refit warm-started from the promoted point, run to convergence
   (`state_fit__…rds`; arguments in `manifest_fit__…txt`, 26 August 2026).
   Final objective 807.96.
4. Diagnostics at the new fit (`manifest_diag__…txt`), then all profiles
   recomputed against the new baseline, with per-parameter spans, over several
   resumed invocations (`state_profile__…rds`; the last invocation is recorded in
   `manifest_profile__…txt`, 27 August 2026). Improvements below the promotion
   threshold were banked, not acted on (`state_profile_subthreshold__…rds`).
5. Figures and metrics from the final fit (`manifest_plot__…txt`, 31 August 2026).

The manifests record the MD5 checksums of `run_all.R`, `model_v2.R` and
`gloser_data_v2.R` used for each run, so the code in the repository can be
checked against the run that produced each result.

## Data

`gloser_data_v2.R` contains the comparison series, embedded as R code:

- anthropogenic copper stocks and flows from Glöser, Soulier and Tercero
  Espinoza (2013), *Environmental Science & Technology* 47(12), 6564–6572,
  <https://doi.org/10.1021/es400069b>: mine production, refining and semis
  for 1961–2010 from SI Table S2, and the remaining series digitised from the
  paper's figures (the method and its validation are described in the file
  header); mine production for 2011–2020 is from ICSG/USGS statistics;
- real copper prices from the World Bank Commodity Price Data and from Tapia
  Cortez et al. (2018), *Palgrave Communications* 4, 8,
  <https://doi.org/10.1057/s41599-017-0060-x>;
- world real GDP growth from the World Bank (indicator NY.GDP.MKTP.KD.ZG),
  used as the demand forcing.

Please cite the original sources when reusing these series.
